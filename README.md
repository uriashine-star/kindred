# Kindred — talk with Sage

An evidence-based relationship coach you can talk to out loud.

**Live:** https://uriashine-star.github.io/kindred/

- **Talk with Sage**: an animated face that listens (Web Speech recognition) and answers aloud with lip-synced speech. Built-in coaching engine grounded in relationship research (Gottman, Reis, Gable, Aron, attachment theory…), with sources shown on every answer and safety routing for crisis or abuse.
- **Ideal Partner Lab**: 23 deep questions across attachment, wellbeing, values, conflict style, your "checklist" and open reflections, ending in a personal profile with green flags, date questions and full references.
- **Optional Claude brain**: paste your own Anthropic API key in Settings for open-ended conversation and a written personal reading. The key stays in your browser and is sent only to api.anthropic.com.

Voice input works best in Chrome, Edge or Safari. Sage is an AI coach, not a therapist.
